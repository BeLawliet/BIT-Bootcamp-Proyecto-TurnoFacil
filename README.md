# TurnoFácil - Proyecto Final Modulo Uno

TurnoFácil es una aplicación web para reservar citas en una barbería o salón de belleza de manera rápida y sencilla.

## Video de presentación

[Descargar video de presentación](./resources/Resultado.mp4?raw=true)

## Funcionalidades

- Consulta de servicios disponibles.
- Registro de nuevas citas.
- Validación de fechas y horarios.
- Prevención de reservas duplicadas.
- Visualización y cancelación de citas.
- Almacenamiento de datos en el navegador.
- Diseño adaptable a dispositivos móviles.

## Tecnologías utilizadas

- HTML5
- JavaScript
- Bootstrap 5
- LocalStorage

## Ejecución del proyecto

El proyecto no requiere instalación de dependencias.

1. Descarga o clona el repositorio.
2. Abre la carpeta en Visual Studio Code.
3. Ejecuta `index.html` utilizando Live Server.
